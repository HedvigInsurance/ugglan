# hCore

Foundational module used by almost every other module: dependency injection, shared domain models, localization,
feature flags, deep links, app state, networking helpers, and UIKit/SwiftUI extensions. No UI components (those are
in hCoreUI).

## What's here

### Dependency injection
- `Dependencies` (singleton container: `add(module:)`, `resolve()`, `remove(for:)`) and `Module` (factory wrapper).
- `@Inject` resolves on access. `@InjectObservableObject` resolves an `@Observable` on first access (not at init, so
  it is safe as an `App` property ahead of DI setup) and holds it in `@State`.
- Convenience accessors such as `Dependencies.urlOpener` (`URLOpener` / `DefaultURLOpener`) and
  `Dependencies.featureFlags()`.

### Feature flags & experiments
- `FeatureFlagsClient` protocol with `UnleashFeatureFlagsClient` (production) and `FeatureFlagsDemo` (all flags off,
  `isDemoMode = true`).
- `FeatureFlagsStore` — `@PersistableStore` `AppStore` exposing a `FeatureData` value per flag; persists the last
  fetch except `isUpdateNecessary` / `osVersionTooLow`.
- `Experiment` — the Unleash experiments/variants a member is in.

### App state & stores
- `ApplicationState` — persisted `Screen` (`loggedIn`, `notLoggedIn`, `impersonation`, …) and locale preferences.
- `ApplicationContext` — actor holding `isLoggedIn` with a Combine publisher.
- `OnboardingPresentationState`, `AnalyticsConsent` — small UserDefaults-backed flags.
- `DevSettingsStore` — `AppStore` for dev-settings toggles.
- `DeleteAccountStatus` — lives here (not hGraphQL) so modules can use it without linking the GraphQL layer.

### Domain models
- Money: `MonetaryAmount` (currency-aware formatting + arithmetic), `Premium` (gross/net, `.sum()`), `ItemCost`,
  `ItemDiscount`, `IntentCost`, `QuoteCost`.
- Insurance: `TypeOfContract`, `ProductVariant`, `AddonVariant`, `Perils`, `InsurableLimits`, `hPDFDocument`,
  `EditType`, `PillowType`, deflection models (`Partner`, `DeflectQuestion`).
- Files: `File` / `FileSource`, `MimeType`, `UploadFile`, `FileUploadManager`.
- Loading: `LoadState<Value>` (a value loaded once and kept, e.g. in a store) and `ProcessingState`.
- GraphQL fragment → model initializers for these types live in App
  (`OctopusClientsImplementation/hCoreModels+Octopus.swift`), not here.

### Localization
- `L10n` — generated by SwiftGen (`Sources/Derived/Strings.swift`); never edit by hand.
- `Localization.Locale` (`sv_SE`, `en_SE`) with a `currentLocale` subject; `L10nDerivation` /
  `TranslationArgumentable` re-render strings after a language change.

### Navigation & cross-module signals
- `DeepLink` — every supported deep link path, URL parsing and display text; `DeeplinkProperty` for query items.
  App's `DeepLinkHandler` routes them.
- `ChatType` — chat entry points; `NotificationCenter` names (`openChat`, `openDeepLink`, `claimCreated`,
  `tierChanged`, …) for app-wide events.

### Utilities
- `publisher(for:)` on `Observable` — watch an `@Observable` property from a non-View context (see Gotchas).
- `Task.withMinimumDuration(_:tolerance:_:)` (minimum elapsed time, also when throwing), `eraseToAnyCancellable()`,
  `delay(_:)`.
- `NetworkClient` / `NetworkError` / `MultipartFormDataRequest` — thin URLSession wrapper for non-GraphQL requests.
- `DateService` (locale-aware formatters, resolved via DI) plus Date/String date and Swedish SSN helpers.
- `Masking` / `MaskType` — validation and formatting for personal numbers, postal codes, emails, phone numbers;
  usable imperatively or as a `ViewModifier`.
- `AskForRating`, `ImpactGenerator`, `SafariView`, `PasteView`, `findScrollView`, `onUpdate(of:perform:)`,
  `uniqued()`, and assorted UIKit/URL/String/Bundle extensions.

## Dependencies
- **No Hedvig module dependencies.** hCore deliberately does not depend on hGraphQL, so feature modules and their
  SwiftUI previews don't link the generated GraphQL code. Fragment → model conversions (and `GraphQLError`'s localized
  description) live in App; add new ones there, not here.
- External: AppStateContainer, AutomaticLog, Environment, Logger, UnleashProxyClientSwift, Disk.

## Gotchas
- `Dependencies.resolve()` calls `fatalError` if nothing is registered — there is no compile-time check.
- Date formatting extensions resolve `DateService` from DI, so they crash if it hasn't been registered (tests too).
- The global `log` is force-unwrapped (`(any Logging)!`, defaults to `DemoLogger`); App replaces it at startup.
- `publisher(for:)` re-arms `withObservationTracking` after each change and delivers on the next main-actor turn
  (observation reports a change before it is applied). It replays the current value on subscribe, and cannot see a
  value set and cleared within one run-loop turn — that needs a hook in the setter itself.
- `TypeOfContract.resolve(for:)` falls back to a substring match before `.unknown`, which can silently pick the
  wrong type when raw values share substrings.
- `UnleashFeatureFlagsClient` has the Unleash URL and client keys inline in the source.
- `Localization.Locale` only supports Swedish locales.
